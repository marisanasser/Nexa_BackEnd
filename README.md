# Nexa Backend

API Laravel da plataforma Nexa.

## Stack

- Laravel 10
- PHP
- PostgreSQL
- Laravel Sanctum
- Laravel Reverb
- Stripe

## Comandos Basicos

```powershell
composer install
php artisan test --testsuite=Unit
php artisan route:list --except-vendor
```
